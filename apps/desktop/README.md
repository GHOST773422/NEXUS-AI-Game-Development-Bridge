# NEXUS Desktop Shell (Tauri 2 + Rust)

This directory contains the Tauri 2 desktop shell scaffolding for Windows 10/11 (64-bit).

**Note:** Rust (`cargo`) and Tauri CLI are not executed inside Google AI Studio's web container. Export this repository to a Windows 10/11 machine with Rust, MSVC Build Tools, and WebView2 installed to build the native binary. See `docs/TAURI_BUILD.md` for full instructions.
